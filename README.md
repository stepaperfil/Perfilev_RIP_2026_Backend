## Предметная область

Веб-сервис для расчёта совокупной стоимости владения активом (Total Cost of Ownership, TCO) — учёт затрат по всем этапам жизненного цикла актива: закупка, ввод в эксплуатацию, техническое обслуживание, ремонт, модернизация, утилизация.

| Термин задания | Что это в проекте |
|---|---|
| Услуга | Этап жизненного цикла актива |
| Заявка | Расчёт TCO — суммирование затрат по всем этапам |

## Технологии

- **Go** + **Gin** — веб-фреймворк, роутинг
- **html/template** — серверная шаблонизация
- **MinIO** — хранение изображений и видео этапов
- **PostgreSQL** + **GORM** — хранение данных
- **REST API** (JSON) — веб-сервис для SPA
- **JWT** + **Redis** — авторизация и блеклист токенов
- **Swagger** — описание методов API
