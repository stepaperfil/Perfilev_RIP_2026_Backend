# Расчёт стоимости владения активом (TCO) — бэкенд

> Учебный проект по курсу «Разработка интернет-приложений». 

## О проекте

Приложение для расчёта совокупной стоимости владения активом (Total Cost of Ownership) за весь срок службы.

| Термин задания | Что это в проекте |
|---|---|
| Услуга | Этап жизненного цикла актива (закупка, эксплуатация, техобслуживание, утилизация) |
| Заявка | Расчёт TCO — суммирование затрат по всем этапам |

## Технологии

- **Go**
- **Gin** — веб-фреймворк, роутинг
- **html/template** — серверная шаблонизация
- **MinIO** — хранение изображений и видео этапов

## Модель данных

Одна коллекция `Stage` (этап жизненного цикла), без БД, статусы: `draft` / `published` / `deleted`.

| Поле | Тип | Описание |
|---|---|---|
| ID | int | идентификатор |
| Status | string | draft / published / deleted |
| Title | string | название этапа |
| Description | string | описание |
| StageType | string | закупка / эксплуатация / ТО / утилизация |
| StageCost | float64 | стоимость этапа, ₽ |
| StageDate | string | дата этапа |
| ImageKey | string | ключ изображения в MinIO |
| VideoKey | string | ключ видео в MinIO |
| Likes | []int | ID пользователей, поставивших лайк |

## API

Три GET-запроса, без сохранения на сервере:

| Метод | URL | Описание |
|---|---|---|
| GET | `/feed?id={id}&next={true\|false}` | Лента: этап по ID, либо следующий опубликованный после него |
| GET | `/draft` | Единственный этап со статусом «черновик» |
| GET | `/list?filter={стоимость}` | Список всех этапов, кроме удалённых, с фильтром по стоимости |

## Установка и запуск

```bash
# 1. Поднять MinIO
docker-compose up -d

# 2. Создать бакет tco-media в консоли http://localhost:9001
#    (login/pass: minioadmin / minioadmin), сделать публичным

# 3. Запустить приложение
go run cmd/tco-app/main.go
```

Приложение: `http://localhost:8080`
Консоль MinIO: `http://localhost:9001`
