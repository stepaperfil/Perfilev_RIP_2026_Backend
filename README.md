## Предметная область

Веб-сервис для расчёта совокупной стоимости владения активом (Total Cost of Ownership, ТСО) — учёт затрат по всем этапам жизненного цикла актива: закупка, ввод в эксплуатацию, техническое обслуживание, ремонт, модернизация, утилизация.

| Термин задания | Что это в проекте |
|---|---|
| Услуга | Этап жизненного цикла актива |
| Заявка | Расчёт ТСО — суммирование затрат по всем этапам |

## Технологии

- **Go** + **Gin** — веб-фреймворк, роутинг
- **html/template** — серверная шаблонизация
- **MinIO** — хранение изображений и видео этапов
